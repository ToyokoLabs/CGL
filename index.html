About this page & how to embed the module

The simulation is one dependency-free ES module, game-of-life.js, rendered to a canvas. Drop it into any page: 

<div id="life"></div>
<script type="module">
  import { GameOfLife } from './game-of-life.js';

  const life = new GameOfLife('#life', {
    cols: 50, rows: 50, cellSize: 10,
  });

  await life.loadPatternFromURL('patterns/glider.txt');
  life.start();
</script>

Pattern files can be plaintext (O alive, . dead, ! comments) or RLE. Patterns are centered on the grid and clipped if they are larger than it. See README.md for the full API and file formats.

ES modules and fetch() are blocked on file:// pages in most browsers, so serve this folder over HTTP — for example python3 -m http.server 8000 — and open http://localhost:8000.
